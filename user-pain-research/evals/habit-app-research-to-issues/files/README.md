# Habitual

A simple habit tracker for iPhone, built with SwiftUI and SwiftData.

## Plans
- **Free:** up to 3 habits, last 30 days of history.
- **Pro ($4.99/month):** unlimited habits, full history, CSV export, themes.

## Built
- Daily check-ins, streaks, reminders, paywall (`Sources/PaywallGate.swift`), local storage (`Sources/HabitStore.swift`).

## Not built yet
- iCloud sync
- Apple Watch app
- Widgets
